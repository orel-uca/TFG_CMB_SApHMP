<h2>SApHMP Code</h2>
Implementation of mixed-integer linear programming (MILP) models for solving p-median hub problems with single allocation and a fixed or variable discount factor.</br>
This code has been generated in Python using Gurobi as solver for the computational studies included in the Bachelor’s Thesis (TFG) of Celia Martín Baturone, a student of the Mathematics degree at the University of Cádiz (Spain).
